# Boundless Routers — Безмежні маршрутизатори (Forge 1.20.1)

Один блок — **маршрутизатор предметів** — і модулі, які в нього вставляють, щоб переносити предмети світом
усіма способами. Модулі сягають на 8 блоків, а з покращеннями дальності — на 16, 32, 64 блоки або **без меж,
у будь-який вимір**; маршрутизатор може працювати **щотіку**. Кожне перенесення видно: від маршрутизатора до
місця тягнеться світна лінія кольору модуля, і по ній летить сам предмет. Натхнення — Modular Routers (desht,
MIT); код, текстури й назви — власні.

## Маршрутизатор

- **Буфер** (1 слот) — через нього проходить кожен предмет. Лійки й труби дістають буфер з будь-якого боку.
- **9 слотів модулів** — модулі працюють по черзі зліва направо щоразу, коли маршрутизатор «спрацьовує».
- **5 слотів покращень** — скільки влізе, без обмеження кількості.
- **Редстоун**: завжди / із сигналом / без сигналу / ніколи / імпульс (раз на кожне ввімкнення сигналу).
- Компаратор показує, наскільки повний буфер. Детектори подають сигнал із боків маршрутизатора; бік, з якого
  детектор подає сигнал, маршрутизатор не слухає — тож власним сигналом він сам себе не вмикає.
- Зламаний маршрутизатор **зберігає модулі й покращення** у своєму предметі (буфер висипається).

Меню: буфер у мідному кільці, яке заповнюється до наступного запуску; під ним мідна шина до модулів —
коли модуль щось робить, по шині біжить світло його кольору, слот і вогник на «передній панелі» спалахують.
Шестерня під модулем (або клік коліщатком по ньому) відкриває його налаштування.

## Модулі

| Модуль | Що робить |
|---|---|
| **Відправник** | кладе предмети з буфера в перший інвентар у своєму напрямку (крізь будь-які блоки, на дальність маршрутизатора) або в прив'язаний |
| **Витягувач** | бере предмети в буфер із сусіднього інвентаря або з прив'язаного |
| **Розподільник** | розсилає предмети в багато прив'язаних інвентарів: по черзі, навмання, спершу ближчі чи дальші |
| **Скидач** | викидає предмети у світ |
| **Метальник** | кидає предмети з налаштованою швидкістю, кутом і поворотом |
| **Будівельник** | ставить блоки з буфера |
| **Руйнівник** | ламає блок у буфер, як незеритова кирка, з шовковим дотиком або **удачею до 10** |
| **Пилосос** | збирає предмети, що лежать навколо (радіус до 64, не далі за дальність маршрутизатора), навколо маршрутизатора чи точки в напрямку |
| **Знищувач** | знищує предмети з буфера |
| **Модуль гравця** | переносить предмети між буфером та інвентарем / бронею / другою рукою / **скринею Енду** прив'язаного гравця, поки маршрутизатор до нього сягає |
| **Детектор** | подає редстоун-сигнал (сила 1–15, слабкий чи сильний), поки в буфері є потрібне |
| **Висувач** | із сигналом висуває лінію блоків із буфера, без сигналу — забирає її назад |

У кожного модуля:
- **напрямок** відносно лицьового боку маршрутизатора (спереду, ззаду, вгору, вниз, ліворуч, праворуч);
- **фільтр** на 9 предметів: білий чи чорний список, збіг за пошкодженням, NBT, тегами або модом;
- **зупинка**: коли модуль щось зробив, наступні модулі цього разу не працюють;
- власний **редстоун-режим**, окрім режиму маршрутизатора.

**Прив'язка**: присядь і клацни модулем по інвентарю (відправник, витягувач, розподільник), або в повітря —
модулем гравця, щоб прив'язати себе. Чанк прив'язаного місця завантажується, поки модуль ним користується.
Місця й гравці, до яких маршрутизатор не сягає, модуль пропускає.

**Що видно**: коли модуль щось переносить, між маршрутизатором і місцем загоряється лінія кольору модуля, по ній
біжить світло й летить сам предмет (блок), а там, де він приземлюється, спалахують іскри. Глушник це вимикає.

## Покращення

| Покращення | Ефект |
|---|---|
| **Швидкість** | −2 тіки між запусками (з 20), аж до кожного тіку |
| **Стос** | подвоює кількість предметів за раз: 1, 2, 4… 64 |
| **Дальність I / II / III** | модулі сягають на 16 / 32 / 64 блоки замість 8 (не додаються: рахується найкраще) |
| **Нескінченна дальність** | будь-яка відстань і інші виміри |
| **Глушник** | без звуків і часточок |

Усі числа можна змінити в `config/boundlessrouters-common.toml`: дальність без покращень і з кожним, найдальше,
куди дивиться відправник і будує висувач (64), чи сягає нескінченне покращення інших вимірів.

## Рецепти

- **Маршрутизатор**: залізо, редстоун, лійка (`IRI / RHR / IRI`).
- **Порожній модуль** ×2: редстоун, папір, золотий самородок. **Порожнє покращення** ×4: золоті й залізні самородки, редстоун, лазурит.
- Модулі — порожній модуль + перлина Енду (відправник), лійка (витягувач), перлина + компаратор (розподільник),
  викидач, роздавач, поршень (будівельник), залізна кирка, око Енду (пилосос), кактус (знищувач), скриня Енду (гравця),
  спостерігач (детектор), липкий поршень (висувач).
- Покращення — порожнє покращення + цукор і редстоун (швидкість), скриня (стос), підзорна труба (дальність I), вовна (глушник).
- Дальність II: дальність I + 2 перлини Енду + 2 золоті злитки. Дальність III: дальність II + 2 ока Енду + 2 алмази.
- **Нескінченна дальність** (важкий крафт): дальність III посередині, зірка Незеру над нею, незеритовий злиток під нею,
  очі Енду обабіч і уламки відлуння по кутах.

## Збірка й перевірки

```
./gradlew build                 # мод: build/libs/boundlessrouters-1.0.0.jar
./gradlew runGameTestServer     # ігрові тести: маршрутизатори в справжньому світі
python3 tools/check.py          # розмітка, текстури, моделі, мови збігаються
```

Текстури малює `tools/gen_textures.py` за розміткою з `tools/layout.py` (вона ж пише `Layouts.java` для коду),
моделі й рецепти — `tools/gen_data.py`, мови (англійська, українська, російська) — `tools/gen_lang.py`.
GitHub Actions збирає мод, запускає ігрові тести й знімає скриншоти з гри в `screenshots/`.
