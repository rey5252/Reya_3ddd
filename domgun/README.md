# DOM Gun (NeoForge 1.20.1)

Штурмова гвинтівка **DOM** з геймплеєм у стилі Call of Duty.

- **ПКМ (утримувати)** — автоматична стрільба (hitscan: куля миттєва, без снаряда). Сліди куль і дим дула — частинками.
- **Присідання (Shift)** — приціл (ADS): наближення, менший розкид і віддача.
- **R** — перезарядка (клавішу можна змінити в налаштуваннях керування). Магазин 30 патронів, витрачає **Патрони DOM** з інвентарю.
- Віддача камери, розкид (гірший у спринті й у стрибку), хедшот ×2, спад шкоди з відстані.
- Хітмаркер (білий — влучання, червоний — хедшот/вбивство) і лічильник патронів на екрані.
- Крафт: гвинтівка — у верстаті (залізо, дозатор, гачок, редстоун, паличка); патрони — залізний самородок + порох + мідний злиток → 16 шт.
- Усе налаштовується в `config/domgun-common.toml` (шкода, дальність, швидкість стрільби, магазин, розкид, віддача...).

## Збірка

```
./gradlew build
```

Готовий `.jar` — у `build/libs/`.

Модель і текстури генеруються скриптом `python3 tools/gen_assets.py` (потрібен Pillow).
