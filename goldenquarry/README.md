# Golden Quarry (NeoForge 1.20.1)

**Золотий кар'єр** — золота скриня-шахтар, яка сама викопує квадратну зону навколо себе шар за шаром аж до корінної породи.

Блок має висоту 2 блоки: знизу темна підставка, зверху золота скриня з темним візерунком і скляною кліткою,
в якій висить бур. Потрібно 2 вільні клітинки по висоті; якщо зламати будь-яку половину, зникає весь кар'єр,
а предмет випадає один раз.

- Навколо зони копання світиться золота рамка (кнопка «Показати зону» вмикає/вимикає її).
- Інтерфейс: зверху 27 слотів для каменю, землі та інших блоків; знизу 27 слотів для руд, злитків і самоцвітів;
  посередині — смуга енергії та прогресу; праворуч — 3 золоті слоти покращень.
- Енергія: кар'єр сам виробляє трохи енергії (40 FE/тік), а ще приймає Forge Energy з кабелів будь-яких модів.
- Покращення: **швидкість** (до 8), **радіус** (до 8, +2 блоки з кожного боку), **удача II / V / X** (діє найвища), **шовковий дотик**, **переплавка** (руди одразу в злитки).
- Рамку зони показати/сховати: присідання + ПКМ порожньою рукою по кар'єру.
- Не копає корінну породу, рідини та блоки з вмістом (скрині, спавнери); поважає приват-зони (BreakEvent).
- Сигнал редстоуну ставить на паузу. Воронки/труби можуть забирати видобуте, а сусідні скрині отримують його автоматично.
- Усе налаштовується в `config/goldenquarry-common.toml`.

## Рецепти

- Кар'єр: `G P G / B C B / G R G` — золотий злиток, алмазна кирка, золотий блок, скриня, блок редстоуну.
- Покращення: `G R G / R X R / G R G` — золото, R і X:
  швидкість — редстоун + цукор; радіус — редстоун + перлина Енду; удача — лазурит + алмаз;
  шовковий дотик — нитка + смарагд; переплавка — редстоун + доменна піч.

## Текстури та модель

Текстури блоку та інтерфейсу зчитані піксель у піксель з референсів у `reference/`:

- `tools/extract_block.py` — сторони скрині (A і B різні, як на фото), клітка, підставка і бур з `reference/block.png`.
- `tools/extract_gui.py` — інтерфейс з `reference/gui.png` (предмети зі слотів прибрані, смуги енергії/прогресу малює гра).
- `tools/gen_model.py` — моделі: підставка, скриня з відкритою кліткою, окрема модель бура (крутиться, коли кар'єр копає).
- `tools/gen_items.py` — текстури покращень.
- `tools/preview_photo.py OUT.png` — рендер блоку з тієї ж камери, що й фото, поруч із фото та картою різниці.

## Збірка

```
cd goldenquarry
./gradlew build
```

Готовий `.jar` — у `build/libs/`, а також у папці `jars/` після збірки в GitHub Actions.
