# Golden Fortune Converter (NeoForge 1.20.1)

**Золотий перетворювач удачі** — механізм, що переробляє руди в кінцевий продукт з удачею (як
«Преобразователь удачи» з LoliUtility на LoliLand). Має авто-вивантаження предметів.

Один блок: золота скриня з візерунком спереду й ззаду, відкрита з боків, над нею скляна клітка;
всередині стоїть великий бур, який повільно крутиться, поки йде переробка.

- Руди кладуться у верхні 27 слотів — руками або трубами/воронками (найкраще зверху). Результат
  з'являється в нижніх 27 золотих слотах і сам іде в сусідні скрині/інтерфейси з боків і знизу.
- Одна руда за операцію (1 с), як при добуванні незеритовою киркою з Удачею модуля.
- Покращення:
  - **Модуль удачі** II / V / X — у свій слот зліва від смуг; рівень модуля = рівень зачарування Удача.
  - **Автоплавка** — переробляє руди одразу в злитки.
  - **Стак** — переробляє всю руду з інвентаря за 1 операцію.
  - **Безкінечний двигун** — скасовує витрати енергії.
- Енергія: 200 FE за руду (+25% за кожен рівень удачі, +50% з автоплавкою). Сам виробляє трохи
  (20 FE/тік) і приймає Forge Energy з кабелів будь-яких модів.
- Сигнал редстоуну ставить на паузу. Усе налаштовується в `config/goldenquarry-common.toml`.

## Рецепти

- Перетворювач: `G P G / B C B / G R G` — золотий злиток, алмазна кирка, золотий блок, скриня, блок редстоуну.
- Автоплавка: `G R G / R X R / G R G` — золото, редстоун, доменна піч.
- Стак: `G R G / R X R / G R G` — золото, редстоун, воронка.
- Безкінечний двигун: `N R N / R X R / N R N` — незеритовий злиток, блок редстоуну, зірка Незеру.
- Модуль удачі: II — `G R G / R X R / G R G` (золото, лазурит, алмаз); V — з модуля II, алмазів і
  блоків лазуриту; X — з модуля V, незеритових злитків і смарагдових блоків.

## Текстури та модель

Текстури блоку та інтерфейсу зчитані піксель у піксель з референсів у `reference/`:

- `tools/extract_ingame.py` — грані блоку (перед, бік, низ, кільце клітки) і бур з кадрів гри в
  `reference/ingame/` (бур виміряно через камеру, підігнану під кути блоку на кадрах).
- `tools/extract_gui.py` — інтерфейс з `reference/gui.png`; золоті картки зі слотів стали
  покращеннями (стак, безкінечний двигун, автоплавка).
- `tools/gen_fortune.py` — модулі удачі з `reference/fortune.jpg`.
- `tools/gen_model.py` — моделі: скриня з кліткою, бур (повільно крутиться) і скло.

## Збірка

```
cd goldenquarry
./gradlew build
```

Готовий `.jar` — у `build/libs/`, а також у папці `jars/` після збірки в GitHub Actions.
