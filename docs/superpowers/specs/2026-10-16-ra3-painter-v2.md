# RA3 Texture Studio v2: «Substance Painter для RA3»

Дата: 2026-10-16. Запит користувача: повноцінна програма для малювання текстур саме для Red Alert 3:
шари з масками, зручне малювання, альфи пензля, тайлінг, маски, заливки, генератори. Швидко, найважливіше;
інтерфейс скромний (доробимо пізніше).

Формат текстур RA3 і вихідні файли не змінюються (див. `2026-10-15-ra3-texture-studio-design.md`):
`Назва.dds` (RGB колір, A alpha-test 96), `Назва_NRM.dds` (з карти висот), `Назва_SPM.dds` (R блиск, B колір гравця).

## Що повторно використовуємо (без змін API)

- `util.js`, `dds.js` (encodeSet, decodeDDS), `tga.js`, `meshes.js`, `preview3d.js`.
- `generators.js` — процедурні генератори (`catalog`, `defaultLayer`, `apply(layer, maps, size, images)`).
- `maps.js` — лише вихідні функції: `buildDiffuse`, `buildNRM`, `buildSPM`, `viewRGBA`, `sanitizeName`,
  `classifyTextureName`, `TEAM_COLORS`. Вони читають `doc.maps`, `doc.settings`, `doc.nrmImport`, `doc.size`,
  тож працюють і з документом v2. Старі `rebuild/applyBrush/overlays` у v2 не використовуються.

## Модель документа v2 (`js/layers.js`, `RA3.layers`)

```
Doc = {
  version: 2, name: 'AUMyTank', size: 512,
  settings: { nrmStrength: 2, invertY: false },
  nrmImport: RGBA | null,
  images: { [id]: RGBA size×size },          // імпортовані картинки (для шарів 'image')
  layers: Layer[],                            // знизу вгору
  maps: { color: RGBA(4n), height: Float32(n), spec: U8(n), team: U8(n) }   // результат (як у maps.js)
}
CHANNELS = ['color','alpha','height','spec','team']
Layer = {
  id, name, kind: 'fill' | 'paint' | 'proc',
  visible: true, opacity: 1,                          // 0..1
  channels: { color, alpha, height, spec, team },     // bool: які канали шар змінює
  heightMode: 'add' | 'replace',                      // 'add': h += (v-0.5)*t ; 'replace': h = lerp(h, v, t)
  material: Material,                                 // для 'fill'
  paint: { [channel]: { value: U8(4n для color, інакше n), cov: U8(n) } },   // для 'paint', канали створюються ліниво
  proc: { type, seed, params },                       // для 'proc' (будь-який тип generators.catalog, вкл. 'image')
  mask: null | { enabled: true, invert: false, paint: U8(n) | null, gen: null | { type, seed, params } }
}
Material = { color: [r,g,b], alpha: 0..255, height: 0..1 (0.5 = рівно), spec: 0..255, team: 0..255 }
```

База композиції: колір 128,128,128,255; висота 0.5; блиск 0; гравець 0 (як у maps.js).

**Композиція шару** (поверх поточного результату C):
- Маска M[i] ∈ 0..1: `gen ? maskgen.generate(...) по C : 1`, помножене на `paint ? paint/255 : 1`; `invert` → 1−M;
  `enabled=false` або `mask=null` → 1. Ефективна сила `t = opacity · M`.
- `fill`: для ввімкнених каналів C → material за `t` (висота за `heightMode`).
- `paint`: як `fill`, але значення й покриття з `paint[ch]`: `t = opacity · M · cov/255`.
- `proc`: копія C → `generators.apply(proc, копія, size, images)` → для ввімкнених каналів C = lerp(C, копія, t).
- `visible=false` → шар пропускається.

## Пензель (`js/brush.js`, `RA3.brush`)

- `ALPHAS`: вбудовані альфи (штампи) — круг (м'якість), квадрат, гранж, бризки, подряпини, сколи, заклепка,
  зірка (радянська), смуги (hazard), плями камуфляжу. `alphaFromImage(rgba, w, h)` — своя альфа з картинки (яскравість).
- `getDab(alpha, sizePx, angleRad, hardness)` → `{ w, h, data: Float32Array }` (кеш).
- `createStroke(opts)` → `{ begin(x,y,p), move(x,y,p), end() }`; `begin/move` повертають масив мазків
  `{ x, y, size, angle, flow }` з урахуванням spacing, size/angle jitter, scatter, followPath, symmetryX/Y (дзеркало
  відносно центру текстури), детермінованих за `seed`.
- `floodRegion(rgba, size, x, y, tolerance)` → `U8(n)` (0/255), заливка області схожого кольору з загортанням країв.

## Маски-генератори (`js/maskgen.js`, `RA3.maskgen`)

`catalog` (метадані параметрів як у generators.catalog) і `generate(gen, maps, size) → Float32Array(n)` 0..1,
безшовні: `edges` (зношені краї — опуклості висоти + розбивка шумом), `cavity` (западини/шви — бруд),
`ao` (затінення з висоти), `height` (діапазон висоти), `noise` (гранж), `gradient` (верх/низ),
`team` (зона кольору гравця), `color` (за кольором з допуском).

## Матеріали RA3 (`js/materials.js`, `RA3.materials`)

- `list`: прості матеріали для пензля й заливок: фарба Альянсу (світла/темна), фарба СРСР (червона/сталь),
  фарба Імперії (біла/графіт), гола сталь, іржа, бруд, гума/гусениці, скло кабіни, бетон, фарба гравця
  (сірий 50% + team 255), тощо — кожен `{ id, label, material, channels }`.
- `smart`: «розумні матеріали» — набори шарів (fill + маска-генератор), напр. «Альянс: фарба зі зношеними краями»,
  «СРСР: червона сталь з іржею», «Імперія: біла броня», «Бетон будівлі». `smartLayers(id, seed) → Layer[]`.

## Проєкт v2 (`js/project.js`)

`serialize(doc)` / `deserialize(json)` підтримують `version: 2` (шари з paint-буферами й масками, deflate+base64);
v1-файли відкриваються з конвертацією (кожен старий шар → `proc`, оверлеї пензля → один `paint`-шар).

## Інтерфейс (скромний)

Верхня панель інструментів: Пензель (B), Гумка (E), Заливка (G), Піпетка (I), «Малювати: Шар/Маска», симетрія X/Y,
тайлінг 3×3 (перегляд), розмір/потік/м'якість. Ліворуч — шари (+ Заливка, + Малювання, + Генератор, + Розумний
матеріал; видимість, непрозорість, ↑↓, видалити, маска). Праворуч — властивості шару/маски, матеріал пензля,
альфи, налаштування пензля, 3D-прев'ю, експорт. Undo/Redo для мазків і заливок.
