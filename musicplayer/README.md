# Хвиля — музичний плеєр

Плеєр у стилі Spotify для телефона. Один файл `index.html`, працює офлайн і встановлюється на головний екран як звичайний застосунок (PWA).

## Що вміє

- **Улюблені, плейлисти, черга** — додавай, перейменовуй, видаляй.
- **Перемішування й повтор** (усіх або одного треку).
- **Таймер сну** і **швидкість відтворення**.
- **Керування з екрана блокування** та навушників (Media Session).
- **Жести:**
  - свайп по обкладинці — наступний / попередній трек;
  - свайп униз — згорнути плеєр;
  - свайп треку вправо — додати в чергу;
  - довге натискання — меню треку.
  - подвійний тап по обкладинці — додати до улюблених.
- **Кольори акценту** — обери свій.
- **6 демо-треків** синтезуються прямо в браузері, тож послухати можна одразу.

## Де зберігається музика

Тільки на твоєму пристрої — у сховищі браузера (IndexedDB). Нічого не вивантажується в мережу. Якщо очистити дані сайту, бібліотека зникне.

## Формати

MP3, M4A/AAC, FLAC, OGG/Opus, WAV — що саме відтвориться, залежить від браузера й системи (найсумісніші — MP3 та M4A). Назву, виконавця й обкладинку плеєр читає з ID3-тегів у MP3 (ID3v1, v2.2–v2.4, зокрема кирилиця у windows-1251). Повторно доданий той самий файл не дублюється.

## Як встановити на телефон

**Android:** найпростіше — встанови готовий [`apk/Hvylia.apk`](../apk/Hvylia.apk): музика грає у фоні, є сповіщення з кнопками. Деталі — у [`android/README.md`](../android/README.md).

**Або як веб-застосунок:**


1. Розмісти папку `musicplayer/` на будь-якому статичному хостингу з **HTTPS**.
   Наприклад, GitHub Pages: **Settings → Pages → Deploy from a branch**, обери гілку й папку `/ (root)`.
   Плеєр буде за адресою `https://<логін>.github.io/<репозиторій>/musicplayer/`.
2. Відкрий адресу на телефоні:
   - **Android (Chrome):** меню **⋮** → «Встановити застосунок» або «Додати на головний екран».
   - **iPhone (Safari):** кнопка «Поділитися» → «На початковий екран».

Після першого відкриття плеєр запускається й без інтернету.

## Запуск локально

```bash
npx serve musicplayer
```

Відкрий показану адресу (`http://<IP-комп’ютера>:3000`) на телефоні в тій самій Wi‑Fi мережі.
Зверни увагу: без HTTPS (крім `localhost`) браузер не встановить застосунок і не ввімкне офлайн-режим — для цього потрібен хостинг із HTTPS.
