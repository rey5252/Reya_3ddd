# Галерея Reya

Галерея для телефона в стилі iPhone: медіатека, альбоми, папки, імпорт цілих папок і окремих файлів, плавні анімації та частинки.
Це вебзастосунок (PWA): він встановлюється на головний екран Android чи iPhone, відкривається на весь екран і працює без інтернету.
Фото й відео зберігаються лише на самому телефоні, у пам’яті застосунку (IndexedDB), нікуди не вивантажуються.

## Що вміє

- **Медіатека**: усі фото й відео за місяцями; режими «Роки / Місяці / Усі фото». Щипок двома пальцями змінює розмір сітки.
- **Імпорт**: кнопка «+». Можна вибрати **кілька папок по черзі** (разом з підпапками) і **окремі файли**. Усе збирається в один список і імпортується разом.
  - «Зберегти структуру папок»: папка стає папкою, а кожна підпапка з фото стає альбомом.
  - «Усе в один новий альбом» або «Лише в Медіатеку».
  - Дублікати пропускаються. Дата зйомки береться з EXIF.
  - На комп’ютері можна просто перетягнути файли й папки у вікно.
- **Альбоми й папки**: створення, перейменування, переміщення в папку, видалення (фото лишаються в медіатеці). «Улюблені», «Відео», «Нещодавно додані», «Нещодавно видалені» (30 днів).
- **Перегляд**: плавний перехід із мініатюри, гортання, масштаб щипком і подвійним дотиком, змахування вниз, щоб закрити, вгору, щоб побачити інформацію. Відео з перемоткою. Слайд-шоу.
- **Вибір**: «Вибрати», потім торкання або протягування пальцем по сітці. Дії: поділитися, в улюблені, додати в альбом, видалити.
- **Довге натискання** на фото чи альбом відкриває контекстне меню з розмиттям, як в iOS.
- **Частинки**: серця, коли додаєте в улюблені; фото розсипаються, коли їх видалити; іскри після імпорту.
- Світла й темна тема, кнопка «Назад» на Android, жест «назад» від лівого краю.

## Як поставити на телефон

Застосунку потрібна адреса `https://`. Найпростіше через GitHub Pages:

1. На GitHub: **Settings → Pages → Source: GitHub Actions**.
2. **Actions → Deploy gallery → Run workflow**. Посилання з’явиться в результаті запуску (щось на кшталт `https://<user>.github.io/<repo>/`).
3. Відкрийте посилання на телефоні:
   - **Android (Chrome)**: меню ⋮ → «Встановити застосунок» / «Додати на головний екран».
   - **iPhone (Safari)**: кнопка «Поділитися» → «На екран “Додому”».

Для перевірки на комп’ютері: `npx http-server gallery` і відкрийте `http://localhost:8080`.

## Обмеження браузерів

- Вибір **папки** працює в Chrome на Android і на комп’ютерах. Safari на iPhone не завжди дає вибрати папку: тоді виберіть усі фото з неї через «Фото й відео».
- HEIC-фото з iPhone показуються в Safari; Chrome на Android їх не відкриває.
- Браузер може обмежити обсяг пам’яті для застосунку; великі відео займають багато місця.

## Файли

- `index.html`: розмітка; `app.css`: стилі.
- `js/core.js`: сховище, частинки, меню й аркуші; `js/pages.js`: екрани й навігація; `js/viewer.js`: перегляд фото; `js/import.js`: імпорт і приклади; `js/main.js`: запуск.
- `sw.js`, `manifest.webmanifest`, `icons/`: усе для встановлення й роботи офлайн.

Якщо потрібен саме APK для Google Play, цю саму папку можна загорнути в Capacitor або PWABuilder без змін у коді.
