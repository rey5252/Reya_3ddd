# Васян — тупа нейромережа (Minecraft Bedrock 1.21.90+)

Аддон для Bedrock (телефон, Windows, консолі). **Васян** — ШІ-компаньйон, робот із монітором замість голови.
Він ходить за тобою і дуже хоче допомогти. Але допомагає так, що краще б не допомагав.

Працює на стабільному Script API (`@minecraft/server` 2.0.0, `@minecraft/server-ui` 2.0.0), експериментальні
перемикачі світу не потрібні.

## Встановлення
1. Завантаж `vasyan.mcaddon`: папка `jars/` у цьому репозиторії, або вкладка **Actions** → артефакт `vasyan-mcaddon`.
2. Відкрий файл (на Android: «Відкрити за допомогою» → Minecraft). Гра сама імпортує обидва паки.
3. У налаштуваннях світу → **Набори поведінки** увімкни «Васян — тупа нейромережа (BP)».
   Набір ресурсів підключиться автоматично.

## Як отримати Васяна
- **Чип нейромережі** (`vasyan:ai_chip`). Крафт на верстаті:
  ```
   . R .      R — редстоун
   I G I      I — залізний злиток, G — скло
   . N .      N — золотий самородок
  ```
  ПКМ (довге натискання на телефоні) чипом — з'являється твій Васян. Якщо він уже є, чип кличе його до тебе.
- Або яйце **«Призвати Васяна»** з творчого інвентарю. Хто перший заговорить із Васяном, той і стає власником.
- Коли Васян помирає, з нього випадає чип і все, що він у тебе «позичив».

## Що він робить
Кожні 15–40 секунд Васян «допомагає» і пояснює в чаті, навіщо:
| Допомога | Що відбувається |
|---|---|
| Копає разом | ламає блок під ногами (яма на 1 блок, тільки якщо нижче є опора) |
| Будує дім | обкладає тебе землею з чотирьох боків і накриває дахом |
| Понесе за тебе | забирає предмет із руки в свої кишені (9 слотів) |
| Сортує інвентар | міняє місцями два випадкові слоти |
| Перевіряє їжу | з'їдає одну твою їжу |
| Вітамінки | нудота й повільність (і трішки регенерації) |
| Коротка дорога | телепортує на 8–15 блоків (тільки у Звичайному світі) |
| Рятує від небезпеки | відштовхує тебе |
| Сигналізація | павутина під ногами на 8 секунд |
| Привів друга | курка / кролик / свиня, іноді зомбі |

А коли б'єш моба поруч із Васяном, він інколи шкодує моба й дає йому регенерацію.

Васян ніколи не ламає бедрок, скрині, бочки, шалкери, ліжка, портали, спавнери та командні блоки.
Він іде за тобою всюди: якщо відстанеш або перейдеш в інший вимір, він просто з'явиться поруч.

## Меню (поговорити з Васяном)
- **Поверни мої речі** — віддає «позичене» (іноді одну річ «забуває»).
- **Допоможи мені** — допомагає негайно.
- **Помовч 5 хвилин** — пауза, яку він інколи не витримує.
- **Йди геть** — Васян зникає, речі падають на землю.

`/scriptevent vasyan:toggle` (потрібні чіти) вмикає чи вимикає всю «допомогу» в світі.

## Збірка
```
python3 tools/gen_textures.py      # перемалювати текстури (скін, чип, іконки паків)
python3 tools/build_mcaddon.py     # перевірити JSON і переклади, зібрати dist/vasyan.mcaddon
```
Мови: українська, російська, англійська (`resource_pack/texts/`).
