# Бобік і Клод (Minecraft Bedrock 1.21.90+)

Аддон для Bedrock (телефон, Windows, консолі) з двома ШІ-компаньйонами, які **говорять вголос**:
у грі звучить голос, а над хотбаром з'являються субтитри. Чат не використовується.

- **Бобік** — тупа нейромережа. Робот із монітором замість голови, низький хриплий голос.
  Ходить за тобою і «допомагає» так, що краще б не допомагав.
- **Клод** — неофіційний клон розумної нейромережі. Білий робот із помаранчевим візором.
  Реально допомагає, б'є монстрів, прибирає за Бобіком і постійно з нього стібеться.

Обидва за замовчуванням матюкаються (вимикається в меню). Говорять українською або російською,
мова перемикається в меню. Працює на стабільному Script API (`@minecraft/server` 2.0.0, `@minecraft/server-ui` 2.0.0),
експериментальні перемикачі не потрібні.

## Встановлення
1. Завантаж `bobik_klod.mcaddon`: папка `jars/` або вкладка **Actions** → артефакт `bobik-klod-mcaddon`.
2. Відкрий файл (Android: «Відкрити за допомогою» → Minecraft).
3. У налаштуваннях світу → **Набори поведінки** увімкни «Бобік і Клод (BP)».

## Як отримати
| Чип | Крафт | |
|---|---|---|
| **Чип Бобіка** | редстоун зверху, залізо–скло–залізо, золотий самородок знизу | ПКМ — з'являється Бобік |
| **Чип Клода** | редстоун зверху й знизу, золото–алмаз–золото посередині | ПКМ — з'являється Клод |

Чип також кличе вже наявного компаньйона до тебе. Ще є яйця виклику в творчому режимі:
хто перший заговорить із компаньйоном, той і стає власником.

## Бобік
Кожні 15–40 секунд Бобік «допомагає» (у бою чи з малим здоров'ям — лише безпечні дурниці): копає яму під ногами, будує «хату» з землі, забирає річ із руки,
міняє місцями речі, з'їдає твою їжу, дає «вітамінки» з нудотою, телепортує «короткою дорогою», штовхає,
ставить павутину, приводить «друга» (іноді зомбі). Бедрок, скрині, ліжка, портали й спавнери він не ламає.

Меню (поговорити з Бобіком): **Поговорити** (анекдот, порада, «де алмази?» — дає «справжній алмаз»,
як справи, «ти тупий?», хто ти), **Поверни мої речі**, **Допоможи**, **Подарувати те, що в руці**
(їжа, редстоун, квіти й блискучі речі — кожне з реакцією; редстоун можна просто дати, торкнувшись Бобіка), **Станцюй**, **Сиди тут / Йди за мною**,
**Помовч 5 хвилин**, **Мати увімк./вимк.**, **Мова**, **Йди геть**.

## Клод
Кожні 25–50 секунд робить щось корисне: забирає в Бобіка вкрадене й віддає тобі, лікує, коли ти поранений,
ставить факели в темряві, підгодовує, дає справжні поради. Б'є монстрів поруч з тобою (нейтральних,
як-от ендермени й піглини, не чіпає). Коли Бобік щось утне, Клод коментує й часто виправляє: засипає яму,
розбирає «хату», прибирає павутину, повертає речі. Бобік, звісно, огризається.

Меню: **Поговорити** (анекдот, корисна порада, як справи, що думаєш про Бобіка, ти розумний?, хто ти),
**Допоможи нормально**, **Станцюй**, **Сиди тут / Йди за мною**, **Помовч**, **Мати**, **Мова**, **Йди геть**.

## Команди
У меню обох є **«Дати команду»**: пиши своїми словами українською, російською (можна суржиком і з помилками)
або навіть англійською. В одному реченні може бути кілька команд, а ім'я каже, кому вони:
«зрубай дерево і збудуй дім», «Клоде, зроби міст, а потім постав факели», «обидва танцюйте».

| Команда | Клод | Бобік |
|---|---|---|
| копай / тунель / шахта | тунель уперед (лише природний ґрунт, біля води й лави зупиняється) | яма під тобою |
| рубай дерево / дрова | рубає найближче дерево (будинки з колод не чіпає) | одна паличка |
| збудуй дім / укриття | хатинка 5×5 з дошок із дверима | «хата» із землі |
| міст | міст із бруківки вперед | стовп із землі під тобою |
| вбий монстрів | б'є монстрів поруч | лікує їх |
| факели / темно | кільце факелів | рівно один факел |
| їсти / голодний | дає хліб | з'їдає твою їжу |
| збери речі / лут | зносить предмети тобі | собі в кишені |
| знайди алмази / руду | шукає руду, іскри показують дорогу | «справжній алмаз» із землі |
| день / ніч | відмовляється: це чіт | перемикає час доби |
| лікуй | регенерація | «вітамінки» |

Обидва також розуміють: за мною, сиди, танцюй, анекдот, посваріться, поверни речі, помовч, йди геть.
Бобік інколи навмисно розуміє все не так. Справжній ШІ з інтернетом у грі на телефоні неможливий
(доступ до мережі скрипти мають лише на виділеному сервері), тому команди розпізнаються за словами.

## Суперечки
Вісім озвучених суперечок між Бобіком і Клодом. Вони починаються самі раз на 3–6 хвилин, з кнопки
«Посваріться» в розмові або командою «посваріться».

## Реакції
Вони коментують, коли тебе б'ють, коли мало здоров'я, після смерті, коли знаходиш алмази, коли настає ніч,
у новому вимірі, коли ти вбиваєш моба, коли починається дощ, коли поруч кріпер, коли ти довго стоїш на місці.
Якщо вдарити свого компаньйона, він скаже «ай», а після трьох ударів поспіль образиться.

Мова й мати налаштовуються окремо для кожного гравця. Команди (потрібні чіти): `/scriptevent vasyan:toggle` — увімкнути/вимкнути пранки Бобіка,
`/scriptevent vasyan:mat` — увімкнути/вимкнути мати.

## Голос
Усі репліки лежать у `tools/lines/<персонаж>_<мова>.json` (`vasyan` — це Бобік, внутрішнє ім'я лишилось
з першої версії). Їх озвучує `tools/gen_voice.py` синтезатором RHVoice
(`apt install rhvoice rhvoice-russian rhvoice-ukrainian ffmpeg`). Він генерує `.ogg`, `sound_definitions.json`
і `behavior_pack/scripts/voice.js` (тексти й тривалість для субтитрів). Переозвучуються лише змінені рядки.

**Звукові ефекти.** `tools/gen_sfx.py` синтезує з нуля (без чужих семплів) вісім комедійних звуків:
«бум», коли Клод стібеться; сумний тромбон, коли в Бобіка не виходить; цвіркуни на незнайому команду;
скретч платівки, коли Бобік зрозумів не так; «дзинь», коли Клод щось виправив; гудок на початку танцю;
«бойнь» на пранки Бобіка; барабанний дріб, коли Клод знайшов руду.

**Свій голос.** Можна записати репліки самому (або попросити друга, якщо він не проти):
```
python3 tools/import_voice.py --list > lines.txt   # список: куди класти файл і який текст сказати
python3 tools/import_voice.py мої_записи/          # мої_записи/vasyan/uk/mat/hello_1.m4a і т.д.
```
Підходить будь-який формат, який читає ffmpeg. Гучність вирівнюється автоматично, решта реплік лишається синтезованою.

## Збірка
```
python3 tools/gen_textures.py      # скіни (звичайні й з відкритим ротом), чипи, іконки паків
python3 tools/gen_sfx.py           # звукові ефекти
python3 tools/gen_voice.py         # озвучка змінених реплік (і реєстрація ефектів)
python3 tools/build_mcaddon.py     # перевірки (JSON, назви, кожна репліка озвучена) і dist/bobik_klod.mcaddon
```
