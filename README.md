# Cursed Seed (NeoForge 1.20.1)

Мод для Minecraft 1.20.1 на NeoForge (47.1.x).

- **Прокляте насіння** (`cursedseed:cursed_seed`) — рідко (2.5% + 1% за рівень Добичі) випадає з візер-скелетів, убитих гравцем.
- ПКМ насінням по траві / землі — ділянка 3x3 стає **Проклятою землею** (чорна).
- На Проклятій землі монстри з'являються часто (навіть удень), з ефектами диму, і вони сильніші:
  +50% здоров'я, +50% урону, +15% швидкості, +4 броні, вогнестійкість на 10 хв.
- Проклята земля повільно розповзається на сусідню траву й землю (у темряві швидше).
- Ламається лопатою; без Шовкового дотику випадає звичайна земля.
- Усі шанси та бонуси налаштовуються в `config/cursedseed-common.toml`.

## Збірка

```
./gradlew build
```

Готовий `.jar` — у `build/libs/`. Також GitHub Actions збирає мод при кожному пуші (вкладка **Actions** → артефакт `cursedseed-jar`).
