# Tiny Mob Farm (NeoForge 1.20.1)

Ферма мобів розміром в один блок.

1. Скрафти **Ласо** (нитка зверху/знизу/з боків, слиз у центрі) і натисни ним ПКМ по мобу — моб потрапить у ласо.
   ПКМ ласом по блоку — випустити моба назад.
2. Постав **ферму мобів** і встав у неї ласо (ПКМ по фермі з ласом у руці або через меню).
   Усередині клітки крутиться маленька копія моба.
3. Ферма видає здобич цього моба так, ніби його вбив гравець (стрижні іфрита, черепи тощо теж падають),
   і сама складає її в сусідні скрині/бочки/воронки. Сигнал редстоуну зупиняє ферму.

| Ферма | Цикл |
|---|---|
| Дерев'яна | 60 с |
| Кам'яна | 45 с |
| Залізна | 30 с |
| Золота | 20 с |
| Діамантова | 12 с |
| Незеритова | 5 с |

Крафт: дерев'яна — колоди по кутах, скло хрестом, воронка в центрі; кожна наступна — попередня ферма в центрі,
скло хрестом і матеріал по кутах (бруківка → залізо → золото → діамант → незерит). Усі рецепти симетричні.

Меню симетричне: зліва ласо, по центру вікно з 3D-мобом на п'єдесталі, справа здобич 3×3, під ними смуга прогресу.
Боса (Дракон, Візер) спіймати не можна.

**Покращення** — у бічних вкладках меню (2 зліва, 2 справа) кладуться зачаровані книги, рівні з кількох книг додаються:
- **Ефективність** — швидше (кожен рівень +50% швидкості, Ефективність IV = у 3 рази швидше);
- **Добича** — більше луту;
- **Вогняний аспект** — м'ясо випадає смаженим;
- **Змах** — більше мобів за один цикл (+1 за рівень).
