# Галерея Reya для Android (APK)

Готовий файл: [`apk/Reya-Gallery-1.3.apk`](../apk/Reya-Gallery-1.3.apk).

## Як встановити

1. Скопіюйте APK на телефон або відкрийте його на телефоні.
2. Торкніться файлу. Якщо Android попросить, дозвольте встановлення з цього джерела («Невідомі джерела»).
3. Натисніть «Встановити». Застосунок з’явиться як «Галерея».

Потрібен Android 7.0 або новіший.

## Що тут усередині

Це та сама галерея з папки [`gallery/`](../gallery), запакована в нативний застосунок (WebView). Під час збирання код з `gallery/` автоматично копіюється в APK.
Що додає Android-частина:

- **Усі фото й відео з телефона** однією кнопкою в «+», з усіма папками (камера, знімки екрана, Telegram…). Фото не копіюються: галерея показує їх там, де вони лежать, тому навіть тисячі фото імпортуються за секунди й не займають місця.
- **Вибір цілої папки** через системний вибір папок Android, разом з підпапками. Можна додавати кілька папок по черзі.
- **Папка Download**: окрема кнопка в «+», бере всі фото й відео із «Завантажень» разом з підпапками (Telegram тощо). Звичайний вибір папок Android цю папку не дає.
- **Поділитися** фото чи відео в будь-який застосунок.
- **Зберегти в галерею телефона** (папка `Pictures/Галерея Reya` або `Movies/Галерея Reya`).
- Кнопка «Назад» Android закриває перегляд, меню й екрани.
- Світла й темна тема за налаштуваннями телефона.

Фото, додані з телефона, лишаються на своєму місці: «Видалити» в галереї прибирає їх лише з галереї, а не з телефона. Якщо видалити сам застосунок, зникнуть тільки альбоми, папки й позначки.

## Збирання

Потрібні JDK 17+ та Android SDK (platform 35).

```
cd android
gradle assembleRelease
```

APK з’явиться в `app/build/outputs/apk/release/app-release.apk`.

Ключ підпису лежить у `keystore/` (пароль `reyagallery`). Він потрібен, щоб нові версії встановлювалися поверх старої без втрати фото. Він стосується лише цього застосунку.
